# MiniShell

A practice product

## 实现功能

| 实现功能                     | 与bash实现行为差异               | 支持异常报错     |
|------------------------------|----------------------------------|------------------|
| 不带复杂参数的单程序调用命令 | 几乎相同                         | 创建程序失败异常 |
| 每条命令的重定向功能         | 以最后重定向指令为主，与bash相同 | 重定向失败异常   |
| 单管道运算符操作命令         | 几乎相同                         | 支持报错         |
| 纯多管道运算操作命令         | 几乎相同                         | 支持报错         |
| shell内置exit命令            | 几乎相同                         | 直接退出不报错   |
